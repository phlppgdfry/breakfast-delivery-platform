# Interface and identity

The primary task is a filterable register with a selected-record inspector, actionable forms and visible outcomes. Four derived metrics and a small comparison panel provide context above it. Navigation remains shallow because the delivered workflow fits one workspace.

Each project owns its SVG mark, favicon, 180 px Apple touch icon, theme colour, browser title, manifest and preview metadata. Marks are original geometric vectors, not third-party logos. Brand text remains real HTML. No external fonts or image hosts are required.

Typography uses Avenir Next/Avenir with Segoe UI and sans-serif fallbacks. Morning Table uses Georgia for its main heading. Body text, forms, focus states and tables share a measured scale; the data register scrolls inside its container on narrow screens. Native progress elements have accessible names. Input labels, error announcements, keyboard buttons, reduced-motion preferences and a skip link are included.

Desktop preview: [preview.png](preview.png). Mobile: [mobile.png](mobile.png). Browser verification checks 390, 768 and 1440 px; keyboard controls and native input constraints remain available. These checks do not substitute for a formal accessibility audit.
